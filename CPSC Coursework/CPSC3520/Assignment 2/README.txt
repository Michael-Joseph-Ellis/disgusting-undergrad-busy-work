This archive contains the following files:

assignment2.ml
This file contains all required OCaml functions for Assignment 2, implemented using pure functional programming principles and recursion. The following functions are included:

first_duplicate : Finds and returns the first duplicate in an integer list, or -10000 if none exist.

sumOfTwo : Determines whether two integers from two separate lists sum to a given value.

list_intersection : Computes the intersection of two lists as a set, preserving order and removing duplicates.

unique : Removes duplicate elements from a list while preserving the order of first occurrences.

powerset : Returns the powerset of a given integer list.

README.txt

All functions follow the assignment constraints, using recursion and avoiding imperative constructs, loops, and disallowed library functions.
